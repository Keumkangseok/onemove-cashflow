# DOWOL DESIGN — 도월 케어 시스템

도월디자인이 시공하는 모든 현장에 케어(CCTV) 시스템을 도입해, 고객이 공사의 시작부터 끝까지 직접 지켜볼 수 있게 하는 서비스 소개 페이지입니다.

- 고객: 현장을 방문하지 않아도 실시간으로 진행 상황 확인, 도난·파손·분쟁에 대한 불안 해소
- 도월디자인: 시공 전 과정 공개로 신뢰 확보, 하자·분쟁 발생 시 영상 근거로 신속 대응, 전담 PM의 원격 현장 관리

> B2B SaaS로 다른 인테리어 업체에 판매하는 구조가 아니라, **도월디자인이 자사 고객에게 직접 제공하는 서비스**로 기획되어 있습니다.

## 현재 상태

정적 HTML/CSS/JS 한 페이지로 구성되어 있습니다. 빌드 도구나 프레임워크 없이 `index.html` 하나로 동작합니다.

- 브랜드 소개, 시공 철학, 문제 정의, 케어 시스템 6가지 기능, 진행 방식, 왜 도월디자인인가, 케어 플랜 안내, FAQ, 상담 예약 폼 포함
- 라이트/다크 모드 대응, 데스크톱·모바일 반응형
- 로고 워드마크("도월디자인 / DOWOL DESIGN")를 실제 로고 이미지를 기반으로 얇은 트래킹 서체로 재현
- 상담 예약 폼은 현재 프론트엔드에서만 동작하는 자리표시자입니다. 실제 접수를 받으려면 백엔드(예: 서버리스 함수, Google Form, 알림톡 연동 등)와 연결이 필요합니다.
- 연락처(02-0000-0000, hello@dowoldesign.kr)와 케어 플랜 가격은 예시이며 실제 값으로 교체가 필요합니다.

## 로컬에서 보기

```bash
open index.html   # 또는 브라우저로 파일을 직접 엽니다
```

## 다음 단계 (제안)

1. **상담 폼 연동** — 실제 상담 신청이 접수·알림되도록 백엔드 연결
2. **카메라 스트리밍 연동** — 상용 CCTV 클라우드 서비스(RTSP/API 제공 업체)와 연동해 실시간 시청 링크 발급
3. **고객 뷰어 페이지** — 링크/QR로 접속하는 실제 시청 화면 (인증, 만료 처리 포함)
4. **담당 PM용 통합 모니터링 콘솔** — 다중 현장·카메라 등록 및 진행 상황 대시보드
5. **실제 연락처/가격 확정** 후 콘텐츠 교체, GitHub Pages 또는 자체 도메인으로 배포
