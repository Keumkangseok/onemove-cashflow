# 안심캠 (ANSIMCAM)

인테리어·리모델링 현장에 CCTV를 설치해 고객이 실시간으로 진행 상황을 확인할 수 있게 하는 "현장 안심" 서비스의 판매용 랜딩페이지입니다.

- 고객: 공사 현장을 방문하지 않아도 스마트폰으로 실시간 확인, 도난·파손·분쟁에 대한 불안 해소
- 인테리어 업체: 안심 인증 배지로 계약 전환율 상승, 클레임 감소, 다중 현장 원격 관리

## 현재 상태 (Phase 1)

정적 HTML/CSS/JS 한 페이지로 구성된 랜딩페이지입니다. 빌드 도구나 프레임워크 없이 `index.html` 하나로 동작합니다.

- 서비스 소개, 문제 정의, 기능, 이용 방법, 업체용 혜택, 요금 안내, FAQ, 상담 신청 폼 포함
- 라이트/다크 모드 대응
- 상담 신청 폼은 현재 프론트엔드에서만 동작하는 자리표시자입니다. 실제 접수를 받으려면 백엔드(예: 서버리스 함수, Google Form, 알림톡 연동 등)와 연결이 필요합니다.
- 브랜드명("안심캠"), 연락처(1588-0000, hello@ansimcam.kr), 요금은 모두 예시이며 실제 값으로 교체가 필요합니다.

## 로컬에서 보기

```bash
open index.html   # 또는 브라우저로 파일을 직접 엽니다
```

## 다음 단계 (제안)

1. **상담 폼 연동** — 실제 상담 신청이 접수·알림되도록 백엔드 연결
2. **카메라 스트리밍 연동** — 상용 CCTV 클라우드 서비스(RTSP/API 제공 업체)와 연동해 실시간 시청 링크 발급
3. **고객 뷰어 페이지** — 링크/QR로 접속하는 실제 시청 화면 (인증, 만료 처리 포함)
4. **업체 관리자 콘솔** — 다중 현장·카메라 등록 및 모니터링 대시보드
5. **실제 브랜드/가격 확정** 후 콘텐츠 교체, GitHub Pages 또는 자체 도메인으로 배포
